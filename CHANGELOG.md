# HiCT Changelog

## Unreleased

- Add a read-only server session snapshot API for edited assemblies, AGP hashes, name overrides, source links, complete rendering graphs, track definitions and workspace state. Revision guards reject capture from stale displayed assemblies; portable v3 save and restore are still under development.
- Validate nested session visualization options, colors, style bundles, preset actions and duplicate bookmark/preset IDs before replacing the map. Preserve legacy empty-style documents and action-preset colormap placeholders without applying invalid styles.
- Reject unsupported session versions, malformed view coordinates and container fields, and oversized or excessively nested session documents before opening files or changing the active map. Legacy imports now explain that edited assemblies, full processing graphs and undo history are not included.
- Refresh contig and scaffold models after secondary replacement, including confirmed mismatches. Keep assembly responses in the primary map's resolution grid so selecting a secondary assembly with a different pyramid does not invalidate the rulers and map coordinates.
- Prepare secondary-source alignment and metadata before replacement, roll back failed layout synchronization, and retain the old source on errors or cancelled compatibility warnings. Successful replacement clears its old FASTA link; primary FASTA aliases are prepared before publishing new links.
- Preserve the active primary map, edited assembly, secondary source, FASTA links and workspace when a replacement map cannot be prepared. Manual Open now retains the live interface until the server accepts the replacement, and failed candidates release their resources.
- Extend navigation diagnostics with real drag-pan checks and browser event-to-view/render timings, and add complete synthetic catalog and legacy session/preset fixtures for reinforcement testing.
- Define prerequisites and expected outcomes for all 232 historical control signatures, distinguish source inspection from functional evidence, and capture dialog ownership to resolve ambiguous controls during the interface audit.
- Add repeatable menu acceptance checks with explicit expected outcomes, API documentation window verification and missing-FASTA recovery checks. Preserve the historical control inventory for source reconciliation without treating visible controls as tested functionality.
- Report declared source units and imported weights consistently when opening, attaching or selecting a secondary source. Disable inapplicable contact-scaling and weight controls with an accessible explanation, including resolutions without imported weights, while preserving legacy behavior when metadata is unknown.
- Establish reinforcement regression fixtures for Log2, custom processing graphs and forward/reverse FASTA coordinates with gaps. Browser acceptance checks now use the actual FASTA and range-scan controls and require mixed-resolution overlays to remain visible; remaining failures are documented as release blockers.
- Right-click works everywhere. On the contact map any point inside a contig opens the menu (before, only a spot within a few pixels of a border did), with the contig and scaffold under the pointer on each axis, plus new Zoom to contig/scaffold, Copy name and Copy position. Menus also exist on 1D tracks (center on or copy a feature, copy coordinates, hide track, open Tracks and layers), on the FASTA strip (copy position or visible sequence, toggle the reverse strand) and on both rulers (copy position, switch the coordinate mode). The browser's own menu no longer appears over the map, tracks or rulers; copying falls back to a text selection when the clipboard API is unavailable (plain HTTP sessions). Copied positions are 1-based, as in genome browsers.
- Ruler labels are no longer cut off at the canvas edges: rotated horizontal labels are kept fully inside the canvas, vertical labels never shrink below 10 px and the vertical ruler reserves the width of its longest label, and long contig/scaffold captions are shortened with an ellipsis.
- The menu bar shows the open Hi-C file and, when attached, the secondary file (full path on hover), the browser tab title is the open file's name, and the sidebar's Primary and Secondary buttons show their files on hover. All attach, detach and close paths keep them current.
- Sidebar layer names are readable (Contig borders, Scaffold borders, Contig names, Scaffold names).
- Contig and scaffold names no longer overlap: contig names now default to below the border and scaffold names above it, a track whose names share a side with the other track's names is offset by one line, and neighbouring names that would collide are dropped in favour of the wider entity (they return on zoom-in). Saved presets and sessions keep their own placement; exports keep every name.
- Smoother panning and zooming on maps with many contigs: borders and names are built only for the contigs near the view with a one-viewport margin and rebuilt exactly when motion stops (a pan no longer rebuilds them on every frame); the FASTA strip coalesces its updates and keeps a request whose range still covers the view; the row/column scope list and the Entities lists show a first window of entries with Show 500 more; contrast-range updates, resolution handling, workspace autosave and UI-setting storage no longer do work on every frame or during motion.
- Menus: the top bar is now File, Assembly, View, Tools, Dev, Help. Connection (API gateway) moved into Dev, About, API docs and Report a bug into Help (which now opens in a new tab), Drop caches into Dev, Tools groups sequence search and dotplots, and map-dependent items are disabled while no map is open. Menu links no longer jump the page.
- The "Normalization settings" dropdown is gone. Pre/post log, resolution and linear scaling, Cooler weights, auto upper threshold and the rendering pipeline button are in a collapsed "Signal processing" section above Apply in the sidebar's visualization editor, and apply with the same button. Auto-threshold and per-source option reloading keep running when another sidebar panel is open.
- The menu bar shows the linked FASTA and loaded AGP as `FASTA: …` / `AGP: …` chips (click to change). The FASTA and AGP pickers show a spinner and ignore repeated Load while working, Load AGP warns that it replaces the current layout, and exports show "Preparing export…" and report failures.
- FASTA mismatch dialog states the verdict, marks failed checks in red and offers "Choose another FASTA". Sequence search, ModDotPlot and dotplot dialogs offer "Link FASTA…" when no FASTA is linked and reopen after linking. Wizard secondary-FASTA warnings are shown.
- Cancelling the optional FASTA picker in "Apply Juicebox assembly" no longer applies the assembly; an in-app dialog (Cancel / Apply without FASTA / Choose FASTA…) replaces the browser confirm.
- Ribbon: search centers contigs and scaffolds on the right map position, supports arrow keys, Enter and click-to-go, and closes on Esc/blur. SVG/PNG/PDF export controls are one "Export" dropdown, so the ribbon fits one row at 1200 px; PNG and PDF metadata now include the signal display mode. Sequence search and ModDotPlot dialogs move explanations and rarely used options into "How this works" / "Advanced" sections, and toolbar icon buttons have accessible names.
- Launcher: launcher settings are loaded from and saved to the same file (HICT_LAUNCHER_CONFIG, else the default data folder when writable, else a per-user file), so a changed DATA_DIR is remembered. Closing the window or pressing Stop while the server runs asks for confirmation. Start checks ports (range, distinct, bindable on the bind host), DATA_DIR writability and confirms non-loopback binding, and never opens a browser if the server already stopped.
- Launcher layout: one Status line (Running, Starting…, Stopped, Stopped unexpectedly with exit code, Port in use by another program), Start/Stop/Re-open shown only when applicable, About and the version in the footer, a data-folder row with Change…/Open folder on first run, configuration grouped with a filter, and log Follow/Copy/Save…/Clear controls.
